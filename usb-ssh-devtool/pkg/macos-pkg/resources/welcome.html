USB SSH Devtool — Mac Client

This installer configures your Mac to connect to a hardened Ubuntu machine via the USB SSH Devtool recovery agent.

It will install:

  • The ED25519 private key in ~/.ssh/
  • An SSH config alias devtool-target
  • The usb-ssh-devtool-connect command

Prerequisite: The usb-ssh-devtool .deb package must already be installed on the Ubuntu target machine.
