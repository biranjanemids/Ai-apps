Installation Complete

Your Mac is now configured with the USB SSH Devtool credentials.

Next steps

  1. Edit ~/.ssh/config — replace REPLACE_WITH_TARGET_IP with your Ubuntu machine's IP address.
  2. Connect: 
    ssh devtool-target
    or: 
    usb-ssh-devtool-connect devrecovery@<ip>
  3. When done, run usb-ssh-devtool-mac-cleanup to remove all artifacts.
